# Quantumult X 脚本合集

平时自己用 Quantumult X，碰到一些比较烦人的广告，就顺手抓包研究一下，写点重写规则。

本来只是给自己用的，既然写了就放到 GitHub 上，万一也有人用得上呢。

目前先放了虎扑，后面碰到其他 App 想折腾的话，也会慢慢加进来。**自用为主，随缘更新**，不保证每个版本都能跟上。

## 📦 目前有的

### 🏀 虎扑去广告（测试版）

目前是针对 **虎扑 iOS 8.2.67** 抓到的两个广告接口写的规则，用 Quantumult X 的 MITM 和响应重写，清空符合条件的广告数组。

只动目前确认的接口，其他地方暂时没碰。**不是全广告过滤**，也可能出现广告位留白。

**订阅地址：**

```text
https://raw.githubusercontent.com/akaagiao1/quantumult-x-scripts/main/hupu/hupu-ad.conf
```

**怎么用：**

1. 复制上面的链接，添加到 Quantumult X 的「远程重写」。
2. 开启重写功能，更新一下远程资源。
3. 开启 MITM，安装并信任证书（已经配置好对应的 hostname，不用重复添加）。
4. 完全退出虎扑，再打开看看效果。

之前如果加过相同接口的本地规则，记得先关掉，避免互相冲突。

## 🔧 一点说明

这些脚本基本都是自己抓包、看接口、边用边改的。

目前的虎扑脚本只处理以下接口：

- `goblin.hupu.com/3/8.2.67/interfaceAd/getOther/v3`
- `goblin.hupu.com/3/8.2.67/interfaceAd/getOther/batch`

响应结构符合预期时会清空 `ads` 数组，不符合就原样放行，尽量别影响正常功能。

App 一更新，接口可能就变了；有些广告也可能来自别的地方，所以不保证一直有效。如果发现失效或有其他问题，可以开个 Issue，有空我会看看。
